# Электроника — каталог товаров

Приложение на Python + Tkinter для продажи электроники.
Работает с SQLite.

## Возможности

- Авторизация по логину (роли: Клиент, Менеджер, Администратор)
- Каталог товаров с картинками, ценами, остатками
- Оформление заказа
- Список заказов и состав (для Менеджера)
- Редактирование даты и удаление позиции (для Администратора)

## Запуск

```bash
python main_catalog.py
